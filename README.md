# dotfiles

Configuration for the tools in my setup (macOS).

## Layout

`home/` does **not** mirror `$HOME` — it is only this repository's own
organization convention. Inside it, `home/.config/` has one directory per tool,
and that is where the `dot-something` files live, including the ones that sit
outside `~/.config` in the home directory (such as `.zshrc` and `.gitconfig`).

```
home/
└── .config/
    ├── git/
    │   └── .gitconfig
    ├── wezterm/
    │   └── wezterm.lua
    └── zsh/
        └── .zshrc
```

Since the path in the repository is not the path in the home directory, every
file's destination is written down in [`links.conf`](links.conf):

```
.config/git/.gitconfig          ~/.gitconfig
.config/zsh/.zshrc              ~/.zshrc
.config/wezterm/wezterm.lua     $XDG_CONFIG_HOME/wezterm/wezterm.lua
```

To add a new configuration: drop the file in `home/.config/<tool>/`, add the
matching line to `links.conf` and run `install.sh` again. A file under `home/`
that is missing from the manifest is reported as a warning at the end of the
run.

## Install

```sh
git clone git@github.com:<user>/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

`./install.sh --dry-run` prints what would happen without changing anything.

The script links file by file, never by directory, so the repository never
takes over a directory that also holds state generated by other tools. It is
idempotent: running it again only fixes whatever is out of place. If a real
file already sits at a destination, it is moved to
`~/.dotfiles-backup/<timestamp>/` before the link is created.

## What is here

| Tool | File | Notes |
| --- | --- | --- |
| zsh | `home/.config/zsh/.zshrc` | Oh My Zsh + powerlevel10k, mise, zoxide, fzf, atuin and aliases |
| git | `home/.config/git/.gitconfig` | delta as pager and diff filter |
| WezTerm | `home/.config/wezterm/wezterm.lua` | rose-pine-moon theme; dims unfocused windows |

## Dependencies

The `.zshrc` assumes these tools are installed — without them the shell opens
with errors:

```sh
brew install mise zoxide fzf atuin direnv eza bat ripgrep fd bottom duf dust \
  procs lazygit git-delta uv
brew install --cask wezterm font-hack-nerd-font
```

Oh My Zsh and the zsh theme/plugins are installed separately:

- [Oh My Zsh](https://ohmyz.sh)
- [powerlevel10k](https://github.com/romkatv/powerlevel10k)
- plugins: `fzf-tab`, `zsh-autosuggestions`, `zsh-syntax-highlighting`,
  `zsh-completions`, `zsh-history-substring-search`

## Kept out of the repository

`~/.p10k.zsh` (generated by `p10k configure`) is not versioned here.
